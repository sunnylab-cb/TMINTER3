## Staged plan

1. Inventory files read-only; record counts, sizes, duplicate IDs, sample
   headers. A file census is NOT proof of complete/current RCSB coverage.
2. Audit mmCIF biological-assembly operators and polymer entities; expand
   biological assemblies, retain copy/operator IDs. Asymmetric-unit chain
   pairs are not automatically biological interactions. Include experimental
   protein structures beyond membrane proteins; record method/resolution,
   observed sequence, missing residues, modified residues and altloc rules.
3. Build partner-specific 5.5A heavy-atom labels in the same residue contract
   as current training. Keep chain-pair labels separate from all-partner
   union. Preserve assembly-context provenance and exact-sequence mappings.
4. Before ANY pretraining, exclude homologues of frozen membrane validation,
   test and designated external holdouts, using the frozen pairwise SI
   implementation/denominator. Audit both partner chains and complex-level
   grouping. Cluster remaining data into RCSB train/validation/holdout.
5. Audit reusable ESMC caches for model, layer selection, sequence hashes and
   residue mapping. The current features are layers12/24/36, 3456D. Generate
   missing features separately. Experimental coordinates create labels,
   not prediction-side ESMFold90D descriptors. Do not swap GT for PS silently.
6. Pilot label/mapping QC, throughput and feature coverage on a fixed small
   sample before scaling. Heavy work uses Slurm, not login-node GPUs.
7. Controlled trials: membrane-only baseline; RCSB-only; RCSB pretraining
   then membrane-train-only fine-tuning. Same downstream architecture/input
   contract and frozen membrane holdouts. Also evaluate a sealed general
   RCSB holdout. More data does not guarantee a higher benchmark score.
